# Rent.lk Project Notes

මෙම application එක proposal එකේ සඳහන් Vehicle Rental Management System workflow එකට ගැලපෙන ලෙස සකස් කරලා තියෙනවා.

## Business Process Mapping

1. Customer Registration / Login
2. Customer Vehicle Browse / Search
3. Vehicle Date Availability Check
4. Online Booking Request
5. Staff/Admin Booking Review
6. Booking Approval / Rejection
7. Payment Record Handling
8. Vehicle Return Update
9. Notifications
10. Reports

## Role Permissions

### Customer
- Register / Login
- View vehicles
- Book vehicles
- View booking history
- View payment history
- View notifications

### Staff
- View pending bookings
- Approve / reject bookings
- Record payments
- Mark vehicle returned
- View notifications

### Admin
- Dashboard
- Manage vehicles
- Manage all bookings
- Manage payments
- View reports
